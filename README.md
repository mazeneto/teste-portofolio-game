# José Neto · Selecione seu player

Tela "Selecione seu player" do portfólio de José Neto, separada como página própria.
Joguinho em pixel art: o José anda pela calçada de Porto Alegre, pula, pega moedas e destrava skills.

## Controles

- Clique no jogo pra começar. Ele vem pra frente da tela e só sai no × da janela.
- Espaço pula (segura pra ir mais alto) · ← → anda · ↓ abaixa · F solta poder (a partir da 1ª skill)
- No celular aparecem botões na tela.

## Publicar no GitHub Pages

Settings → Pages → Deploy from a branch → `main` / raiz.

Tudo é estático: `index.html` + `img/`.
